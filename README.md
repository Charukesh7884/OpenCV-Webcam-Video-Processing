# OpenCV Webcam Video Processing

## Overview

This project demonstrates real-time webcam image acquisition and video processing using Python and OpenCV.

The notebook captures live video from the webcam and performs several image processing operations such as frame capture, resizing, and rotation. It also shows how to display images using Matplotlib and save processed frames to the local system.

The project is designed for Digital Image Processing laboratory practice and helps in understanding the fundamentals of computer vision, webcam handling, and real-time frame manipulation using OpenCV.
____

## Technologies Used

- Python
- OpenCV
- Matplotlib
- Jupyter Notebook

---

## Features

### 1. Image Acquisition from Webcam
Capture a frame from the webcam and save it as a JPG image.

### 2. Display Captured Image
Load and display the saved image using Matplotlib.

### 3. Live Video Streaming
Display real-time webcam video feed.

### 4. Video Frame Resizing
Resize webcam frames dynamically before displaying them.

### 5. Video Rotation
Rotate webcam frames clockwise and display the transformed video.
